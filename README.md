# Zahlenraten-Spiel
Ein kleines Python-Spiel. Der Computer wählt eine Zahl zwischen 1 und 100, und ich muss sie erraten.
Dabei habe ich Schleifen, Bedingungen und Eingaben gelernt.
## So startest du das Spiel
1. Python installieren (python.org)
2. Die Datei `zahlenraten.py` herunterladen
3. Im Terminal eingeben: `python zahlenraten.py`
